# 压缩记忆

- 日期：2026-04-28
- 主题：logger 增加终端颜色区分

## 目标

- 解决服务端日志纯白输出难读的问题，让时间、级别、作用域和附加信息在终端里更容易扫读。

## 改动

- `shared/logger.ts`
  - 新增 ANSI 颜色输出。
  - 时间使用暗色，`INFO/WARN/ERROR` 分别用蓝/黄/红，作用域统一用青色高亮。
  - 附加 JSON 信息使用暗色，降低视觉噪音。
  - 保留 `NO_COLOR` 开关，非 TTY 场景自动退回纯文本。

## 验证

- `npm run backend:check`
- `npm run test`
