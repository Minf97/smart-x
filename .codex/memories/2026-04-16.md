# 项目创建进度和本地仓库路径

- 目标：修正创建项目的 repoId / repoName 使用，增加创建进度反馈，设置页支持本地仓库路径。
- 改动：
  - 创建项目改为 session + poll，进度步骤包括 `listProjectRows`、`validateProjectConnection`、`createBackendProject`、`cloneManagedRepo`、`saveProject`。
  - 设置页新增 `RepoPathField`，支持编辑本地仓库路径和打开目录。
  - 默认本地仓库路径当前为 `~/Documents/workspace/managed-repos/<provider>/<repo segments...>`。
  - clone / 更新仓库统一走 `ensureManagedRepo`，尽量复用已有目录。
- 验证：`biome check` 通过，`tsc --noEmit --skipLibCheck` 通过。
- 待办：后续可增加系统“选择文件夹”对话框。

- 目标：参考用户手改的 `validateProjectConnection`，把项目创建/更新逻辑写得更直白，并调整 memory 规则。

  - 合并并删除旧的按任务拆分 memory 文件。
