# 实现主链路状态流转

## 目标

- 按 `docs/main-flow.md` 实现 Phase 1 的 Alert 状态闭环。
- 分析时进入 `in_progress`，创建 Code Request 后进入 `in_review`，合并后进入 `done`。

## 改动

- `src/server/alerts/repository.ts`
  - `analyzeAlert` 开始时把 `backlog/todo` 推进到 `in_progress`。
  - `createAlertRequest` 成功后把 Alert 状态更新为 `in_review`。
  - `mergeAlertRequest` 成功后把 Alert 状态更新为 `done`。
- `src/components/dashboard/alert-cache.ts`
  - 新增 dashboard alerts cache 更新 helper。
- `src/components/dashboard/analysis-action.tsx`
  - 分析开始时按同样规则做 `in_progress` 乐观更新。
- `src/components/dashboard/request-actions.tsx`
  - 创建 / 合并 Code Request 成功后同步更新前端 Alert 状态。
- `docs/main-flow.md`
  - 更新当前代码覆盖情况，移除已完成的状态流转缺口。

## 验证

- `npm test`
- `npm run check`
