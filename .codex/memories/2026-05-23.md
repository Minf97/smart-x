# 告警按 group-key 聚合

- 目标：相同问题重复上报时只保留同一条告警，避免自动模式重复创建 MR。
- 改动：`backend/src/db.ts` 入库前按 `projectId + groupKey` 查重，命中后通过 `backend/src/alert-cluster.ts` 合并次数、最近时间、优先级和最新原始告警，并重新标记为未同步；`src/server/alerts/repository.ts` 本地同步也按同组更新，保留本地状态和分析。
- 验证：`npm run test -- alert-cluster.test.ts`、`npm run test -- alert-status-flow.test.ts`、`npm --prefix backend run check`、`npm run test`。
- 待办：已有历史重复本地告警不会自动清理，可后续补迁移或清理脚本。

# 按标题生成 groupKey 并优化左侧组行

- 目标：放宽默认 groupKey，让同标题报警收敛到同一组，并在左侧列表按 group 展示。
- 改动：`backend/src/alert-normalizer.ts` 未显式传 `groupKey` 时改用 `title` 的 sha1；`SidebarPanel` 行内展示标题、次数、优先级和最近时间；更新 webhook/API 文档说明。
- 验证：`npm run test -- alert-normalizer.test.ts alert-cluster.test.ts sidebar-panel-group.test.tsx`、`npm --prefix backend run check`、`npm run test`、改动文件 `biome check`。
- 待办：历史旧 groupKey 不自动重算。
